# GameCloud — starter website

This is a complete static frontend starter for a cloud-gaming-style website.

## Run locally
Open `index.html` in a browser.

## Deploy
Upload the files to any static hosting provider.

## Important
This package does NOT contain commercial games or a cloud GPU backend. The included games are library placeholders so the UI can be tested immediately.

For true cloud gaming, add:
1. A legal game build on a remote machine/GPU.
2. A session manager that creates a game instance.
3. A signaling server.
4. WebRTC video/audio streaming.
5. WebRTC data-channel or equivalent input transport.
6. Authentication and session limits.

WebRTC is designed for real-time media and data transport in browsers.
